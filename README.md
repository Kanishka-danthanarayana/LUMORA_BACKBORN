# LUMORA BACKBORN • Precision CNC Suite

A high-performance, modular creative utility suite designed for professional CNC workflows. LUMORA BACKBORN consolidates precision tools for nesting, splitting, slotting, and SVG path manipulation into a single, premium industrial interface.

## 🚀 Getting Started

To run LUMORA BACKBORN on your local machine, follow these steps:

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your system (Version 18 or higher recommended).

### 2. Installation
Open your terminal in this directory and install the necessary dependencies:

```bash
npm install
```

### 3. Launching the Suite
Start the development server to launch the application:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

## 🛠️ Included Tools

### 💎 Image Studio
- **Precision Nesting**: Optimize part placement for material efficiency.
- **Image Splitter**: Segment complex designs for multi-stage processing.
- **Slotter**: Generate precision slots for interlocking assemblies.

### ⚡ SVG Forge
- **Tab Injector**: Programmatically inject structural tabs into SVG paths for stable CNC cutting.

## 📁 Deployment
To create a production-ready build:

```bash
npm run build
```

The output will be generated in the `dist` folder, ready for deployment to any static web host.
